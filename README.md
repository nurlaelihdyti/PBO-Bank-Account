## Deskripsi
Program simulasi bank sederhana dengan class Account, Customer, dan Bank.
- Bank menyimpan nasabah memakai Array.
- Customer menyimpan rekening memakai ArrayList.
- Dilengkapi menu ATM sederhana memakai Scanner.

## Cara Menjalankan
1. Pastikan JDK sudah terpasang.
2. Kompilasi: `javac Account.java Customer.java Bank.java BankDemo.java`
3. Jalankan: `java BankDemo`

## Library Tambahan
Tidak ada library tambahan. Hanya memakai java.util.ArrayList dan java.util.Scanner bawaan Java.
